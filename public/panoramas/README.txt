Official NASA 360° imagery for MARS EXPLORER
============================================

The `nasa/` directory is the canonical panorama source used by the game.
It is generated by `scripts/build-nasa-panoramas.mjs`; do not edit those
files by hand.

Two kinds of imagery are bundled:

1. `kind: surface` — official NASA/JPL rover and lander mosaics resolved
   through the NASA Image and Video Library API
   (https://images-api.nasa.gov). Each file is a same-origin derivative of
   the official asset so the browser does not have to hot-link
   `images-assets.nasa.gov` (whose CORS headers are inconsistent). These are
   the only panoramas used for singleplayer guessing rounds; there are 67 of
   them across 7 landing regions. Provenance is in `nasa/PROVENANCE.txt`.

2. `kind: orbital` — virtual 360° reconnaissance views rendered from the
   official NASA Mars Trek WMTS global mosaic (Viking MDIM 2.1, ~232 m/px).
   These are used only by the globe exploration view (map textures and POI
   quick facts). They are filtered out of singleplayer by `SURFACE_ROUNDS` in
   `src/data/nasaPanoramas.ts`, so orbital imagery can never appear as a
   guess target.

The top-level `*.png` panoramas in this folder are legacy procedural
placeholders. They are kept only as a defensive fallback and are no longer
used for gameplay.

Source references:
- NASA Image and Video Library: https://images.nasa.gov/
- NASA Mars Trek: https://trek.nasa.gov/mars/
- NASA Mars 2020 raw images: https://mars.nasa.gov/mars2020/multimedia/raw-images/

Images must be properly attributed when used. No Earth imagery should be
presented as Martian imagery.
