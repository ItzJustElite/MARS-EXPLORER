This directory contains Martian panoramic image assets.

Supported formats:
- Equirectangular JPEG/PNG for Pannellum
- Cubemap sets (6 face images)

NASA rover imagery can be obtained from:
- https://mars.nasa.gov/mars2020/multimedia/raw-images/
- https://pds.nasa.gov/ (Planetary Data System)

Images must be properly attributed when used.
No Earth imagery should be presented as Martian imagery.
